# DREAM STORE — Interactive Strategic Presentation
### Brand, Content & Marketing Development Strategy
**Presented by ProMedia**

---

## 📖 Overview
An interactive digital strategic presentation for **Dream Store (Since 1998)**, detailing the brand transformation from "Just a Retail Store" to a comprehensive technology brand with personality, history, experience, and community.

- **Client:** Dream Store
- **Presented by:** ProMedia
- **Core Campaign:** "من أول موبايل… لحد اللي بتحلم بيه." (*From the first phone to the future.*)
- **Year:** Since 1998 / 2026 Strategy

---

## 🚀 Key Features
- **13 Interactive Strategic Sections** covering Brand Challenge, Brand Identity, The Big Idea, The Geek character, Content DNA, Nostalgia Timeline (Since 1998), Community, Entertainment, Products, Store Experience, Omnichannel, Future Vision, and Loyalty & Rewards.
- **Cinematic Presentation Mode:** 16:9 widescreen layout with smooth transitions, keyboard controls (`←` / `→` / `Space`), and progress bar.
- **Master Slide Inspector:** Instant high-res original slide comparison modal.
- **Interactive Points & Tier Simulator:** Interactive spend-to-points and loyalty rewards calculator.
- **Audio Synthesizer FX:** Built-in Web Audio synthesis for interactive sound effects.
- **Arabic-First RTL Design:** Modern typography with Cairo, Tajawal, and Plus Jakarta Sans.

---

## 🛠️ Tech Stack
- HTML5 / CSS3 / JavaScript (ES Modules)
- Tailwind CSS & Lucide Icons
- Web Audio API
- Vite & Zero-dependency Node.js server

---

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/<username>/dream-store-presentation.git
cd dream-store-presentation
```

### 2. Install dependencies & run
```bash
npm install
npm run build
node serve.js
```
Then open [http://localhost:3000](http://localhost:3000) in your browser.

Or simply double-click `run-presentation.bat` on Windows.
